# shelf

> A personal skill library for coding agents. Keep Agent Skills (SKILL.md folders) in one library, borrow them into projects, and let loans expire when nobody uses them.

This is a fixture for the site build's tests; the real preamble is docs/llms.md.

- Every command takes `--json` and never prompts.
- The library lives in `~/.shelf/library`; borrowed copies go to `.agents/skills` and `.claude/skills`.
